Session partial Local run

Stopped by the operator after 11 h 41 min with 2 of 31 task cards done and no playable game. Every one of the 33 sessions ran on the model and budget of its role. Qwen's reviewer prompts were refused by MLX-Serve for memory (PrefillDoesNotFit) while both models were resident; Tenaz retried the same refused prompt until it blocked the run, and after one reload of Qwen the refusal came back, so the run was stopped.

Compare attempts →Measurements ↓

What was checked

  • Bootstrap (Qwen, 4 sessions): spec, verify and task cards each accepted on the first attempt: 107 requirements, 31 task cards. One session went over its 42,598-token budget and was continued in a fresh session.
  • T001 (skeleton): the Bonsai builder reached the 40-turn limit and finished in a continuation; verify passed. The reviewer prompt was 281,465 bytes on build b5e5c4a because the bookkeeping commit had put node_modules in git and the list of changed files was not clipped; fx could not send it (ContextCapacityExceeded) 7 times in a row and Tenaz blocked the run. On build 78f5743 the prompt was 86,635 bytes, with the marker [... clipped 3138 lines]; the reviewer accepted T001.
  • T002 (seeded PRNG, fixed-timestep loop): the first review asked for changes; the second attempt was accepted.
  • T003 (terrain): three builder attempts, each passing Tenaz's verify; the first two reviews asked for changes. The review of attempt 3 never finished: MLX-Serve refused Qwen's reviewer prompt in 8 sessions (025-031 and 033), and session 032 went over its budget and was continued.
  • The last committed checkpoint (T002 done) passes 5 project checks in Tenaz's own verify; T003's attempt 3 passes 7. The checks were not rerun independently. The page shows the terrain work in progress, not a game.
  • Every session used the model and context budget of its role: 7 builder sessions on Bonsai at 85,196 tokens and 26 bootstrap and reviewer sessions on Qwen at 42,598. All 443 engine requests that carried tokens matched MLX-Serve log lines whose context fits the role: 301 at 131,072 (builders) and 142 at 65,536 (bootstrap and reviewers).

Limits of this evidence

Operator actions, with times in UTC: 29 Oct 22:37:51, resumed on Tenaz build 78f5743 (from b5e5c4a) after the run blocked on the T001 review, without touching run.json or node_modules; 30 Oct 06:00:31, unloaded and reloaded Qwen through MLX-Serve's API to clear its hot cache after the run blocked on the T003 review, then resumed; 06:32:09, stopped the run (paused) when the memory refusal came back. Before this run, Flint (RecursiveSI/flint-int4) was tried as builder beside Qwen: loading it unloaded Qwen, and with both contexts pinned at 65,536 the hot cache budget fell to 0 MB, so Tenaz's preflight failed (the engine did not reuse the cached prompt prefix). Tenaz's preflight tests only the main model. Not a clean single-version run: two Tenaz builds were used. No build of this attempt is published.
