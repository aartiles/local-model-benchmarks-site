25 October 2026 · Agentic game · isometric 3D

Digger 3D · Sushi 1.2.4

Session completed Local run

Built a complete, playable Digger 3D under the same settings that stopped all three Splash Q2_0 attempts: TypeScript check, 28/28 self-tests, validation of all five levels and the production build pass, and the browser shows a bright isometric board where excavation is visible and enemies chase the player. In the operator's hands-on review its presentation was judged more polished than the 2026-10-02 Sushi 1.1.0 build.

Play build ↗Compare attempts →Measurements ↓

What was checked

  • tsc --noEmit passed, npm test reported 28/28 PASS, npm run validate:levels passed for all five levels and npm run build produced the JavaScript bundle when rerun after the session.
  • Browser check, about 45 s of scripted input and 30 s idle: movement and digging with visible excavation, an emerald collected, firing, Nobbins spawning (2 of 6) and chasing; enemies took lives from 3 to 1 while idle, each death resetting the level while keeping score and lives as the prompt specifies. No page errors.
  • The model's own test loop found and fixed five simulation bugs before finishing, among them movement without input, gold bags skipping their landing row, ghost bags and enemies crossing rock without digging.
  • No response reached the 16,384-token output limit; the largest was 10,401 tokens.
  • A full level, level transition and game over were not played in the browser.

Limits of this evidence

Sushi 1.2.4 (MLX 0.32.3) was started from the previously installed binary kept beside the newer 1.3.0, with the same arguments as the workstation's launcher: 131,072 context, KV8, MTP with MTP-head KV quant, prefill chunk 512, one prefix-cache entry, 20 GB SSD prefix cache, 16,384 output tokens, temperature 0, memory preflight skipped and /metrics on. The engine was loaded before the session and served no other client during it. Sushi does not report TTFT in this log; peak memory was not sampled.
