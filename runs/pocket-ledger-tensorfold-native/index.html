The orchestrator reached COMPLETE without intervention in 5 h 9 min. All 16 model-planned tasks are done, and the project's verify passes 50 checks. What was checked

  • Bootstrap was accepted on its first session. The orchestrator validated 20 requirements, 16 task cards, an acyclic dependency graph, full requirement coverage and a deterministic verify (two identical --all results).
  • Each task was accepted only after the orchestrator itself ran verify --all and verify --task <ID> (at least one passing task check) and a fresh reviewer session returned ACCEPT. T002 and T004 were sent back once by their reviewers. T015 was retried because its first attempt added no task check.
  • The T004 attempt-2 reviewer fell into a repetition loop in its reasoning (about 14k output tokens) and wrote no verdict. That task was accepted on verify alone.
  • The T013 builder was aborted at 60 turns. It had finished the code by about turn 25, then alternated rewriting its handover note and counting its lines. Its work passed verify and review.
  • Independent check after the run, outside the orchestrator: import of a two-month CSV with quoted commas, doubled quotes, DD/MM/YYYY dates and "-1,234.56" amounts; dry-run; duplicate skip on re-import; rules and recategorize; budget warning; report with over-budget mark and month-over-month change; undo; export and re-import with no loss; exit code 2 for bad dates, amounts, IDs and options; a corrupt data file reported with exit 1 and left unchanged. All behaved as specified, except that import --dry-run prints "added N" rather than a would-add wording.

Limits of this evidence

The engine and orchestrator settings were tuned only once before this run (enable --thinking, then a 2 GiB prompt cache with --prompt-cache-over-cap). After the run the orchestrator was changed: a windowed repeat-call watchdog, a reviewer retry when no verdict is written, contextBudget 0.65, and softer note-length rules. Later runs use a different configuration and are not repetitions of this one. Memory was not sampled during the run.
