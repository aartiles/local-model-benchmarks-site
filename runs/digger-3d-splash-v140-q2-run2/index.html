Second attempt under the 16,384-token output limit. After reading the prompt and listing the folder, the model planned the whole game inside one reasoning turn, hit the output limit without a tool call, and Pi ended the session after 4.7 minutes with no code written.

Compare attempts →Measurements ↓

What was checked

  • Pi recorded 3 successful assistant responses and 3 tool calls; the last response ended with stopReason=length at exactly 16,384 output tokens and contained only reasoning, so Pi had no tool call to answer and exited with code 0.
  • The project folder still held only the prompt file after the run.

Limits of this evidence

Splash 1.4.0 (Homebrew) served the model with --max-context=131072 under the name Qwen3.8-Flash-Next-Splash-Q2_0. The startup log reports 128K context, routed experts resident in memory (32,402 MiB) and the per-layer n-gram table streamed from its file (27,465 MiB on the SSD), and warns that with --verify-rows auto greedy and seeded outputs can differ from run to run for this MoE target. Splash had released its weights after 600 s idle before runs 2, 3 and the 64K-output variant and restored them in about 8.4 s before the first request, which is inside the first request's TTFT. Splash reports TTFT and decode rate, not a standalone prefill rate, draft acceptance or peak memory.
