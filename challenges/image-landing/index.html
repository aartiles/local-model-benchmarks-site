Task requirements & full brief

Tenaz gives the agent a generate_image tool backed by ComfyUI with FLUX 3 Image Klein on the same Mac, and unloads the language model while each image is made. The automatic checks cover sizes, provenance, loading and layout; the quality and consistency of the images are judged by eye. No transcripts are published; the model's image prompts are in the build's manifest.

  • A hero, three feature cards, a full-width section over a background image, a closing call to action and a footer.
  • Every image from the runner's generate_image tool, at most 8 calls, with a fixed size and seed per slot and no text in the images.
  • One visual family: the same product, palette and light in every image.
  • Static files with no build step, readable at 1440 and 390 px with a clean console.
  • A manifest of every image call, and checks that each image is the file the tool returned.

How to read this comparison

Compare the generated builds and the checks recorded for each attempt. There is no normalised quality score, and the cloud task’s cumulative token totals and end-to-end rate include repeated context, reasoning, tool calls and waiting — they are not comparable with local per-request decode or prefill rates. The method page sets out which figures can and cannot be set against each other.
