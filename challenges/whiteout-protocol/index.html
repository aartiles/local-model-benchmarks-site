Challenge brief

Each attempt produces its own browser game build. The run records describe the available checks for that build, from production-build and runtime checks to short gameplay exercises. Read the original challenge prompt on GitHub; project transcripts are not published.

  • Playable first-person movement and aiming in a snowy arena.
  • Wave-based combat, enemy damage, player health, and redeployment.
  • Weapon feedback, ammunition, reload, and combat HUD.
  • Separate archived build and run sheet for each attempt.

The GPT-6 Luna prompt file is byte-identical to the local Sushi run's prompt file. Shared prompt text does not make project scaffolds or harness behavior identical.

How to read the comparison

  • Compare the generated games and the checks recorded for each run. There is no repeated or normalized quality score.
  • The Codex cumulative token rate includes reasoning, tool calls, generated tool output, and waiting. It is not comparable to local per-request decode or prefill rates.
  • The GPT-6 Luna record has no independent gameplay acceptance score. The local run sheets show their own build and gameplay checks.

Each future attempt for this workload should have its own immutable run sheet, build artifact, and capture when one is available.
