Task requirements & full brief

The prompt specifies a browser-based third-person platform course with a fair, physically achievable route. The recorded run sheet lists the retained route validator, desktop/touch smoke check and headless completion trials.

  • Complete all ten stages using the implemented movement physics.
  • Support desktop keyboard and mouse plus simultaneous multi-touch movement, jump and camera control.
  • Include hazards, moving and rotating obstacles, disappearing platforms and conveyors.
  • Activate checkpoints, respawn safely, finish the course and restart.
  • Show stage, elapsed time and deaths during play, then show completion time and deaths.

How to read this comparison

Compare the generated builds and the checks recorded for each attempt. There is no normalised quality score, and the cloud task’s cumulative token totals and end-to-end rate include repeated context, reasoning, tool calls and waiting — they are not comparable with local per-request decode or prefill rates. The method page sets out which figures can and cannot be set against each other.
