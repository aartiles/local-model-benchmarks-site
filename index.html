All runs ↓Challenges ↗

These are hands-on experiments with local models on my hardware, designed to test more than tokens per second. Long-context and agentic tasks—planning, tool use, building, and checking results—help me find which model and runtime setups work best for practical tasks on this machine.

Most runs are one-shot unless noted: I submit one task prompt and do not intervene or manually edit the result. The published artifact is what the run produced; each run sheet records its setup, checks, and limitations.
